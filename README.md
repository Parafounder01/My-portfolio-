A modern, responsive portfolio website redesigned with inspiration from Webflow's design language. Features a sophisticated dark theme with a refined purple accent palette, clean typography, smooth scroll animations, and mobile-first responsive design.

---

## Design System

This portfolio was built using design tokens generated by [`getdesign`](https://www.npmjs.com/package/getdesign) (`npx getdesign@latest add webflow`), which produced a comprehensive `DESIGN.md` file inspired by Webflow's visual language.

### Key Design Decisions

| Token | Value | Source |
|-------|-------|--------|
| **Primary** | `#080808` (near-black) | Webflow ink |
| **Accent** | `#7a3dff` (purple) | Webflow 5-stop chromatic system |
| **Font** | Inter (400/500/600) | WF Visual Sans substitute |
| **Radius (buttons)** | 4px `rounded-sm` | Webflow tight geometry |
| **Radius (cards)** | 8px `rounded-md` | Webflow card chrome |
| **Eyebrow labels** | 13px/500/1.5px tracking UPPERCASE | Webflow signature |

## Tech Stack

- **HTML5** — Semantic markup, ARIA accessibility, Open Graph meta tags
- **CSS3** — Custom properties, CSS Grid, Flexbox, responsive breakpoints, keyframe animations, scroll-triggered reveals
- **JavaScript (ES6+)** — Intersection Observer for active nav + scroll reveals, form validation, mobile nav with keyboard support
- **Font Awesome 6** — Icon library
- **Inter** — Primary typeface (Webflow's WF Visual Sans substitute)
- **JetBrains Mono** — Monospace for technical tags

## Features

- Fully responsive (mobile, tablet, desktop) with 3 breakpoints
- Smooth scroll navigation with active section highlighting
- Mobile hamburger menu with animation and Escape key support
- Scroll-triggered fade-in animations with staggered delays
- Floating particle background in hero section
- Contact form with validation and status messages
- Print-friendly styles
- Fast load — no heavy frameworks
- WCAG-compliant contrast ratios
